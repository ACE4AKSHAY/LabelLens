# Team kickoff

1. Person 2 establishes the shared contracts and initial scaffold on `main`.
2. Person 1 and Person 3 clone the repository after that starter commit is pushed.
3. Work in separate branches: `feat/a-ui`, `feat/b-extraction`, and `feat/c-rules`.
4. Person 2 integrates small changes and keeps `main` runnable.
5. Commit and push every 30–45 minutes. Never commit API keys or `.env` files.

See `docs/LabelLens_Modular_Vibe_Coding_Document.md` for the full build guide. The role assignment in the repository README and this file is the current assignment if the older document describes a different integration owner.
